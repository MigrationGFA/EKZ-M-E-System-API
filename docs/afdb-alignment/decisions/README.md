# Architecture Decision Records (ADRs)

Each ADR captures a structural decision that is hard or expensive to reverse, so future readers can see *why* the system is shaped the way it is.

## Status legend

- **Proposed** — drafted by engineering using industry-standard defaults; awaiting client / stakeholder confirmation.
- **Accepted** — confirmed by the relevant decision-maker.
- **Superseded by NNNN** — replaced; see referenced ADR.
- **Deprecated** — no longer in force; kept for historical context.
